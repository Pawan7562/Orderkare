# OrderKare 🍽️ — Multi-Tenant QR Dining & Restaurant Management SaaS

OrderKare is a next-generation Multi-Tenant SaaS platform for restaurants, cafes, and hotels. It powers contactless digital QR menu rendering, real-time WebSocket kitchen operations, table assignments, and super admin platform management.

---

## ✨ Features

- **📱 Dynamic Customer QR Menu**: High-res digital menu (Swiggy/Zomato card layout), live cart with floating bar, Veg/Non-Veg filters, and live kitchen order tracker.
- **🔥 Real-time Kitchen POS Console**: Kanban workflow for incoming table orders powered by WebSocket audio & status updates.
- **👑 Super Admin Management**: Multi-tenant workspace directory, SaaS subscription plans, global analytics, and maintenance toggles.
- **⚡ Serverless Cloud Database**: Powered by Neon PostgreSQL with Prisma ORM & WebSocket driver adapter.
- **💎 Clean Light Theme**: Crisp, modern corporate aesthetic.

---

## 🚀 Quick Start

### 1. Backend Setup
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
